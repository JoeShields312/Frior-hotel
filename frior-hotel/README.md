# Friðr — boutique sauna hotel

Responsive fictional hospitality website built with HTML, CSS, and vanilla JavaScript. Includes four room selections, floating saunas, experience dialogs, and a demo availability form. The latest design includes wooden Norse guardians and a mountain-photo booking section.

## Run locally
Open `index.html` in a browser. All runtime images, fonts, CSS, and JavaScript are embedded. No installation, build command, or server is needed.

## Upload to GitHub
Extract this ZIP, then upload its contents to your repository. Keep `index.html` at the repository root. Upload the extracted files, not the ZIP itself.

## Hosting
This is a static site. Serve the repository root; there is no build step. For GitHub Pages, select deployment from your main branch and the root folder in the repository Pages settings. For Vercel, import the repository as an Other/static project with no build command and use the repository root as the output.

## Files
- `index.html`: complete, higher-quality website.
- `assets/`: separate optimized images and fonts for editing, plus font license.
- `generated_images/`: original generated artwork.
- `IMAGE-PROMPTS.md`: image generation notes.

The hotel, prices, and availability form are fictional. The form does not create reservations or take payments.
